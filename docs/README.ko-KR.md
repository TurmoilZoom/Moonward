업스트림 Starward를 바탕으로, 자주 쓰는 작업을 데스크톱 바로 가기와 URL 하나로 모으고 가챠, 전적, 게임 설치, 배경 등을 강화했습니다. 주요 기능:

#### 가챠

- **가챠 기록** — 배너 통계를 드래그로 정렬, 통계 상단 고정. 목록 보기와 컴팩트 아이콘 그리드 보기를 전환할 수 있음. 연속 UP / 연속 꽝, 픽업 성공 확률을 한눈에 볼 수 있습니다
- **필터와 공유** — 제목 표시줄 드롭다운으로 표시할 배너를 고르고 전체 선택 / 반전 / 초기화 가능. 한 번에 매트 스타일 공유 이미지를 만들며 천장 횟수와 대천장 진행도를 포함
- **가챠 동기화** — 원신(중국 서버)과 젠레스 존 제로는 미유사에서 기록을 동기화할 수 있고, 젠레스 존 제로는 HoYoLAB도 지원. 아직 없는 신규 아이템을 뽑으면 아이콘과 이름을 자동 보완. 아이템 이름은 앱 언어를 따름
- **별바다 세계** — 기원 기록 페이지가 가챠 기록 페이지와 같은 기능(필터, 컴팩트 보기, 드래그 정렬, 공유 이미지)을 제공. 업스트림에 없는 아이템 아이콘을 보완
- **UIGF** — UIGF 가챠 기록 가져오기 / 내보내기

#### 전적과 도구 상자

- **매일 출석** — 미유사 / HoYoLAB 출석, 게임별 독립 스위치, 자동 출석과 보출석. 트레이에 상주하는 동안에는 매일 초기화 후 자동으로 한 번 더 출석
- **로그인 개선** — 중국 서버는 휴대폰 인증 코드, 국제 서버는 웹 로그인. 로그인이 만료되면 가능한 한 자동으로 이어져 반복 로그인할 필요가 없음
- **전적 자동 갱신** — 계정과 데이터 항목(월간 보고서의 이번 달과 지난달 포함)별로 갱신 주기를 정하면 앱 시작 시 자동으로 갱신
- **월간 보고서와 실시간 노트** — 도구 상자 월간 보고서(개척일지 / 월간 로프넷 / 여행자 다이어리) 레이아웃 통일. 월간 로프넷은 서버 시간대 기준으로 일일 데이터를 집계하고 기본으로 이번 달을 표시. 원신 실시간 노트는 더 많은 항목을 표시. 리스크 컨트롤에 걸리면 인증 입구를 제공
- **전적 표시** — 전적과 월간 보고서를 공유 이미지로 만들 수 있음. 환상극에서는 체험 캐릭터와 지원 캐릭터를 표시하고, Anomaly Arbitration에서는 빠른 클리어와 난이도 이름을 표시
- **클라우드 게임** — 클라우드 원신과 클라우드 젠레스 존 제로의 남은 플레이 시간을 확인하고, 매일 무료 시간을 자동으로 받을 수 있음

#### 실행

- **여러 실행 프로필** — 같은 게임에 실행 인수와 사용자 지정 실행 프로그램을 개수 제한 없이 저장. 프로필마다 DX12 인수와 CMD로 실행할지를 따로 설정할 수 있고, 이름을 붙여 저장하고 데스크톱 바로 가기를 만들 수 있음
- **서드파티 도구** — 사용자 지정 실행 프로그램에 URL 프로토콜 링크도 지정 가능. 자주 쓰는 명령줄 인수에 BetterGI, 젠레스 존 제로 OneDragon, March7th Assistant 그룹을 내장
- **URL 프로토콜** — `moonward://`로 게임, 프로필, 계정을 지정해 바로 실행 / 중지 / 재시작하거나 출석만 실행. 스크립트나 웹 페이지에 넣을 수 있음 (자세한 내용: [docs/UrlProtocol](UrlProtocol.md))
- **빠른 실행** — 홈 햄버거 메뉴에 게임 설정, 빠른 실행, 게임 바로 가기를 모음. 바로 가기는 UAC 프롬프트 없이 실행할 수 있고, 관련 예약 작업은 설정에서 게임별로 관리할 수 있음
- **플레이 시간** — 게임이 실행되는 동안 게임 시작 버튼에 타이머를 표시. 플레이 시간 통계는 게임 전환, 연월 지정, 공유 이미지 생성을 지원. PC가 절전 상태였던 시간은 플레이 시간에 포함하지 않음

#### 설치와 업데이트

- **하드 링크 서버** — 게임을 업데이트하거나 복구할 때 하드 링크로 파일을 공유하는 다른 서버도 함께 처리(항상 본체를 먼저 업데이트). 제거 대화 상자는 같은 게임의 설치된 서버를 모두 보여 주며 한꺼번에 제거할 수 있음
- **설치 옵션** — 젠레스 존 제로는 전체 리소스와 기본 리소스 중에서 선택 가능. 설치 경로 옆에 디스크 종류(SSD / HDD / 이동식 / 네트워크)를 표시. Chunk 다운로드는 청크 단위로 병렬 실행
- **복구와 버전 정보** — 게임 복구가 별도 대화 상자로 바뀌었고 Miliastra Sandbox만 따로 복구할 수도 있음. 검증 스레드 수는 디스크 종류에 맞춰 조정. 게임 설정의 「버전 정보」 페이지에 버전, 증분 패치, 메인 실행 파일의 MD5를 표시. 자동 찾기로 앱 안에서 설치한(하드 링크 포함) 게임을 다시 찾을 수 있음

#### 외관과 배경

- **호감 벽지** — 젠레스 존 제로에서 백과의 「호감 동적 벽지」와 「마인드스케이프 정적 벽지」를 받아 사용자 지정 배경으로 설정할 수 있음. 랜덤 모드는 시작할 때, 게임을 전환할 때, 트레이에서 열 때 벽지를 바꿈. 갤러리를 열면 로컬 캐시를 쓰고, 백그라운드에서 조용히 업데이트를 확인
- **사용자 지정 배경** — 별도의 사용자 지정 배경 대화 상자, 이미지 / 동영상 지원(홈에 끌어다 바로 교체). 배경 목록이 갱신된 뒤에도 포스터 선택을 유지
- **동영상 배경** — 하드웨어로 디코딩할 수 없는 동영상 배경은 자동으로 H.264로 변환. HEVC / VP9 확장이 없으면 설치를 안내하거나 정지 이미지를 표시. 화면이 꺼지면 디코더를 해제해 CPU를 헛되이 쓰지 않음
- **홈 도구 모음** — 타임라인(배너 / 이벤트 카운트다운), 중국 서버 특별 방송 리딤 코드, 인터랙티브 맵(원신 / 붕괴: 스타레일)

#### 기타

- **트레이 상주** — 로그인 시 트레이로 자동 시작 가능. 상주하는 동안에도 전역 단축키와 게임패드 조작을 쓸 수 있고, 트레이 메뉴에서 이 기능들을 켜고 끄거나 업데이트를 확인할 수 있음
- **LAN 동기화** — 로컬 네트워크의 다른 기기에서 가챠 기록, 도구 상자 데이터, 플레이 시간을 가져옴. 이 PC에 없는 기록만 추가하고 계정 로그인 정보는 동기화하지 않음
- **데이터 관리** — 데이터베이스, 캐시, 로그, 배경을 선택한 폴더 한곳에 저장. 설정에서 데이터베이스 백업과 캐시 정리가 가능. 처음 실행할 때 업스트림 Starward에서 데이터를 가져올 수 있음(읽기 전용, 원본 데이터는 바꾸지 않음)
- **피드백** — 정보 페이지에서 환경 정보를 한 번에 미리 채워 GitHub 피드백 페이지를 열고 로그 폴더도 함께 염
- **자동 업데이트** — 새 버전을 백그라운드에서 내려받고(트레이 상주 중에도 주기적으로 확인) 종료할 때나 다음 실행 때 설치. 플레이 시간을 기록 중인 게임이 있으면 중단하지 않음. 설치 후 업데이트 내용을 표시. 업데이트 패키지는 먼저 CNB에서 받고, 실패하면 GitHub를 사용(Velopack)

설치 패키지는 [GitHub Releases](https://github.com/TurmoilZoom/Moonward/releases)를 참고하세요. 중국 본토에서는 [CNB](https://cnb.cool/TurmoilZoom/Moonward/-/releases)에서도 받을 수 있습니다.
