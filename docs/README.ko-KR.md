업스트림 Starward를 바탕으로, 자주 쓰는 작업을 데스크톱 바로 가기와 URL 하나로 모으고 출석, 가챠, 배경 등을 강화했습니다. 주요 기능:

#### 가챠

- **가챠 기록** — 배너 통계를 드래그로 정렬(가장자리에 가까우면 가로 자동 스크롤), 목록 드래그 스크롤, 통계 상단 고정. 연속 UP / 연속 꽝, 당첨 확률을 한눈에 볼 수 있습니다. 별바다 세계의 「천장」은 진행 바로 표시
- **필터와 공유** — 제목 표시줄 드롭다운으로 표시할 배너를 고르고 전체 선택 / 반전 / 초기화 가능. 한 번에 매트 스타일 공유 이미지를 만들며 천장 횟수와 대천장 진행도를 포함
- **가챠 동기화** — 원신 / 젠레스 존 제로 등은 미유사 관련 방식으로 기록을 갱신할 수 있습니다. 아직 없는 신규 캐릭터를 뽑으면 아이콘과 이름을 자동 보완. 아이템 이름은 앱 언어를 따름
- **데이터 호환** — UIGF 가챠 기록 가져오기 / 내보내기. 업스트림 Starward에서 기록을 읽기 전용으로 가져올 수 있음

#### 계정과 도구 상자

- **매일 출석** — 미유사 / HoYoLAB 출석, 게임별 독립 스위치, 자동 출석과 보출석. 바로 가기 / URL / 명령줄로 게임을 실행할 때도 해당 계정만 한 번 더 출석
- **로그인 개선** — 중국 서버는 휴대폰 인증 코드, 국제 서버는 웹 로그인. 로그인이 만료되면 가능한 한 자동으로 이어져 반복 로그인할 필요가 없음
- **월간 보고서와 실시간 노트** — 도구 상자 월간 보고서(개척일지 / 월간 로프넷 / 여행자 다이어리) 레이아웃 통일. 월간 로프넷은 시간대를 넘나드는 일일 데이터를 고치고 기본으로 이번 달을 표시. 실시간 노트가 리스크 컨트롤에 걸리면 인증 입구를 제공

#### 실행

- **여러 실행 프로필** — 같은 게임에 실행 인수와 사용자 지정 실행 프로그램을 개수 제한 없이 저장. 프로필을 바꾸거나 인수를 고칠 때 매번 다시 입력할 필요 없이 이름을 붙여 저장하고 데스크톱 바로 가기를 만들 수 있음
- **URL 프로토콜** — `moonward://`로 게임, 프로필, 계정을 지정해 바로 실행 / 중지 / 재시작하거나 출석만 실행. 스크립트나 웹 페이지에 넣을 수 있음 (자세한 내용: [docs/UrlProtocol](UrlProtocol.md))
- **빠른 실행** — 홈 햄버거 메뉴에 게임 설정, 빠른 실행, 「시작 메뉴 바로 가기 만들기」를 모음

#### 외관과 배경

- **호감 벽지** — 젠레스 존 제로에서 백과의 「호감 동적 벽지」와 「마인드스케이프 정적 벽지」를 받아 사용자 지정 배경으로 설정할 수 있음. 갤러리를 열면 로컬 캐시를 쓰고, 백그라운드에서 조용히 업데이트를 확인
- **사용자 지정 배경** — 별도의 사용자 지정 배경 대화 상자, 이미지 / 동영상 지원(홈에 끌어다 바로 교체). 트레이에서 복원할 때 깜빡이지 않음. 배경 목록이 갱신된 뒤에도 포스터 선택을 유지

#### 기타

- **시스템 연동** — 로그인 시 트레이로 자동 시작 가능. 정보 페이지에서 진단 정보를 미리 채우고 GitHub 피드백으로 이동하며 로그 폴더를 한 번에 염
- **무음 업데이트** — 새 버전을 백그라운드에서 받고, 종료 후 자동 설치, 다음 실행 때 업데이트 내용을 표시 (Velopack + GitHub Releases)
