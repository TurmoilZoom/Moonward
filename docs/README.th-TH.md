ต่อยอดจาก Starward ต้นน้ำ โดยรวบการใช้งานที่พบบ่อยไว้ในทางลัดบนเดสก์ท็อปและ URL เส้นเดียว และเสริมกาชา บันทึกการต่อสู้ การติดตั้งเกม พื้นหลัง ฯลฯ ฟีเจอร์หลัก:

#### กาชา

- **บันทึกกาชา** — สถิติแบนเนอร์ลากเพื่อจัดลำดับได้และตรึงไว้ด้านบน; สลับได้ระหว่างมุมมองรายการกับตารางไอคอนแบบกะทัดรัด; ดู UP ติดกัน / พลาดติดกัน และอัตราชนะ 50/50 ได้ในพริบตา
- **ตัวกรองและแชร์** — ดรอปดาวน์ในแถบชื่อเลือกแบนเนอร์ที่จะแสดง พร้อมเลือกทั้งหมด / กลับการเลือก / รีเซ็ต; คลิกเดียวสร้างภาพแชร์สไตล์กระจกฝ้า พร้อมจำนวนการสุ่มและความคืบหน้าการการันตี
- **ซิงก์กาชา** — Genshin Impact (เซิร์ฟเวอร์จีน) และ Zenless Zone Zero ซิงก์บันทึกจาก miHoYo BBS ได้ ส่วน Zenless Zone Zero รองรับ HoYoLAB ด้วย; เมื่อได้ไอเทมใหม่ที่ยังไม่มีในแคตตาล็อก จะเติมไอคอนและชื่อให้อัตโนมัติ; ชื่อไอเทมตามภาษาของแอป
- **มิเลียสตรา วันเดอร์แลนด์** — หน้าบันทึกการอธิษฐานทำงานเหมือนหน้าบันทึกกาชา (ตัวกรอง มุมมองกะทัดรัด ลากจัดลำดับ ภาพแชร์); เติมไอคอนไอเทมที่ต้นน้ำขาดไป
- **UIGF** — นำเข้า / ส่งออกบันทึกกาชาแบบ UIGF

#### บันทึกการต่อสู้และกล่องเครื่องมือ

- **เช็คอินรายวัน** — เช็คอิน miHoYo BBS / HoYoLAB เปิดปิดแยกต่อเกม รองรับเช็คอินอัตโนมัติและเช็คอินย้อนหลัง; ขณะอยู่ในถาดระบบจะเช็คอินอีกครั้งหลังรีเซ็ตรายวัน
- **ปรับปรุงการเข้าสู่ระบบ** — เซิร์ฟเวอร์จีนใช้รหัส SMS ทางโทรศัพท์ เซิร์ฟเวอร์ต่างประเทศใช้การเข้าสู่ระบบทางเว็บ; เมื่อเซสชันหมดอายุจะพยายามต่ออายุอัตโนมัติ ไม่ต้องเข้าสู่ระบบซ้ำบ่อย ๆ
- **อัปเดตบันทึกอัตโนมัติ** — กำหนดความถี่แยกตามบัญชีและหมวดข้อมูล (รวมถึงเดือนปัจจุบันและเดือนก่อนของรายงานรายเดือน); อัปเดตอัตโนมัติเมื่อเปิดแอป
- **รายงานเดือนและบันทึกเรียลไทม์** — รายงานรายเดือนในกล่องเครื่องมือ (ปฏิทินรายเดือนผู้บุกเบิก / รายงานรายเดือน Inter-Knot / บันทึกนักเดินทาง) ใช้เลย์เอาต์เดียวกัน; รายงาน Inter-Knot นับข้อมูลรายวันตามเขตเวลาของเซิร์ฟเวอร์ และแสดงเดือนปัจจุบันเป็นค่าเริ่มต้น; บันทึกเรียลไทม์ของ Genshin Impact แสดงรายละเอียดมากขึ้น; เมื่อติดระบบควบคุมความเสี่ยงจะมีทางเข้าสำหรับยืนยันตัวตน
- **การแสดงบันทึก** — บันทึกการต่อสู้และรายงานรายเดือนสร้างภาพแชร์ได้; Imaginarium Theater ระบุตัวละครทดลองและตัวละครสนับสนุน, Anomaly Arbitration แสดงการผ่านด่านแบบรวดเร็วและชื่อระดับความยาก
- **คลาวด์เกม** — ดูเวลาเล่นคงเหลือของ Cloud Genshin และ Cloud Zenless Zone Zero และรับเวลาฟรีรายวันอัตโนมัติ

#### การเปิดเกม

- **โปรไฟล์เปิดเกมหลายชุด** — บันทึกพารามิเตอร์เปิดเกมและโปรแกรมเปิดเกมแบบกำหนดเองได้ไม่จำกัดต่อเกม; แต่ละโปรไฟล์ตั้งค่าพารามิเตอร์ DX12 และการเปิดผ่าน CMD แยกกันได้ ตั้งชื่อบันทึกและสร้างทางลัดบนเดสก์ท็อปได้
- **เครื่องมือบุคคลที่สาม** — โปรแกรมเปิดเกมแบบกำหนดเองใส่เป็นลิงก์โปรโตคอล URL ได้; พารามิเตอร์บรรทัดคำสั่งที่ใช้บ่อยมีกลุ่มสำหรับ BetterGI, ZZZ OneDragon และ March7th Assistant
- **โปรโตคอล URL** — `moonward://` ระบุเกม โปรไฟล์ และบัญชี เพื่อเริ่ม / หยุด / รีสตาร์ทได้ทันที หรือสั่งเช็คอินอย่างเดียว ฝังในสคริปต์หรือหน้าเว็บได้ (ดู [docs/UrlProtocol](UrlProtocol.md))
- **เปิดเร็ว** — เมนูแฮมเบอร์เกอร์หน้าแรกรวมการตั้งค่าเกม เปิดเร็ว และทางลัดเกม; ทางลัดเปิดเกมได้โดยไม่มีหน้าต่าง UAC และจัดการงานตามกำหนดเวลาที่เกี่ยวข้องแยกตามเกมได้ในการตั้งค่า
- **เวลาเล่นเกม** — ขณะเกมทำงาน ปุ่มเริ่มเกมจะแสดงตัวจับเวลา; สถิติเวลาเล่นสลับเกม เลือกปีและเดือน และสร้างภาพแชร์ได้; ไม่นับช่วงเวลาที่คอมพิวเตอร์อยู่ในโหมดสลีป

#### การติดตั้งและอัปเดต

- **เซิร์ฟเวอร์ที่ใช้ฮาร์ดลิงก์** — เมื่ออัปเดตหรือซ่อมแซมเกม จะจัดการเซิร์ฟเวอร์อื่นที่ใช้ไฟล์ร่วมกันผ่านฮาร์ดลิงก์ไปพร้อมกัน (อัปเดตตัวหลักก่อนเสมอ); หน้าต่างถอนการติดตั้งแสดงเซิร์ฟเวอร์ที่ติดตั้งไว้ทั้งหมดของเกมเดียวกัน และถอนพร้อมกันได้
- **ตัวเลือกการติดตั้ง** — Zenless Zone Zero เลือกติดตั้งทรัพยากรแบบเต็มหรือแบบพื้นฐานได้; ข้างพาธติดตั้งแสดงประเภทดิสก์ (SSD / HDD / แบบถอดได้ / เครือข่าย); ดาวน์โหลดแบบ Chunk ทำงานขนานกันทีละบล็อก
- **การซ่อมแซมและข้อมูลเวอร์ชัน** — การซ่อมแซมเกมแยกเป็นหน้าต่างของตัวเอง และซ่อมเฉพาะ Miliastra Sandbox ได้; จำนวนเธรดตรวจสอบปรับตามประเภทดิสก์; หน้า「ข้อมูลเวอร์ชัน」ในการตั้งค่าเกมแสดงเวอร์ชัน แพตช์ส่วนเพิ่ม และ MD5 ของไฟล์โปรแกรมหลัก; การค้นหาอัตโนมัติหาเกมที่ติดตั้งผ่านแอป (รวมถึงฮาร์ดลิงก์) กลับมาได้

#### รูปลักษณ์และพื้นหลัง

- **วอลเปเปอร์ความไว้ใจ** — ใน Zenless Zone Zero ดาวน์โหลด「วอลเปเปอร์ความไว้ใจแบบเคลื่อนไหว」และ「วอลเปเปอร์ Mindscape แบบนิ่ง」จากวิกิแล้วตั้งเป็นพื้นหลังกำหนดเองได้; โหมดสุ่มจะเปลี่ยนภาพเมื่อเปิดแอป สลับเกม หรือเปิดจากถาดระบบ; เปิดแกลเลอรีแล้วใช้แคชในเครื่องทันที และตรวจอัปเดตเงียบ ๆ ในพื้นหลัง
- **พื้นหลังกำหนดเอง** — กล่องโต้ตอบพื้นหลังกำหนดเองแยกต่างหาก รองรับรูปภาพ / วิดีโอ (ลากมาวางหน้าแรกเพื่อแทนที่ได้); หลังอัปเดตรายการพื้นหลังยังคงตัวเลือกโปสเตอร์
- **พื้นหลังวิดีโอ** — วิดีโอที่ถอดรหัสด้วยฮาร์ดแวร์ไม่ได้จะถูกแปลงเป็น H.264 อัตโนมัติ; หากไม่มีส่วนขยาย HEVC / VP9 แอปจะแนะนำการติดตั้งหรือแสดงภาพนิ่งแทน; เมื่อปิดหน้าจอจะปล่อยตัวถอดรหัส ไม่กิน CPU โดยเปล่าประโยชน์
- **แถบเครื่องมือหน้าแรก** — ไทม์ไลน์ (นับถอยหลังแบนเนอร์ / กิจกรรม), รหัสแลกรางวัลจากไลฟ์สตรีม (เซิร์ฟเวอร์จีน) และแผนที่อินเทอร์แอกทีฟ (Genshin Impact / Honkai: Star Rail)

#### อื่น ๆ

- **ทำงานในถาดระบบ** — ตั้งให้เปิดอัตโนมัติไปที่ถาดระบบเมื่อเข้าสู่ระบบได้; ขณะอยู่ในถาดระบบ ปุ่มลัดส่วนกลางและการควบคุมด้วยเกมแพดยังใช้ได้ และเมนูถาดระบบเปิดปิดฟีเจอร์เหล่านี้หรือตรวจหาอัปเดตได้
- **ซิงก์ผ่าน LAN** — ดึงบันทึกกาชา ข้อมูลกล่องเครื่องมือ และเวลาเล่นเกมจากอุปกรณ์อื่นในเครือข่ายเดียวกัน; เพิ่มเฉพาะบันทึกที่เครื่องนี้ยังไม่มี และไม่ซิงก์ข้อมูลการเข้าสู่ระบบบัญชี
- **การจัดการข้อมูล** — ฐานข้อมูล แคช บันทึก และพื้นหลังเก็บรวมไว้ในโฟลเดอร์ที่เลือก; ในการตั้งค่าสำรองฐานข้อมูลและล้างแคชได้; เปิดครั้งแรกนำเข้าข้อมูลจาก Starward ต้นน้ำได้ (อ่านอย่างเดียว ไม่แก้ไขข้อมูลเดิม)
- **แจ้งปัญหา** — หน้าเกี่ยวกับกรอกข้อมูลสภาพแวดล้อมล่วงหน้าในคลิกเดียว เปิดหน้าแจ้งปัญหาบน GitHub และเปิดโฟลเดอร์บันทึกพร้อมกัน
- **อัปเดตแบบเงียบ** — ดาวน์โหลดเวอร์ชันใหม่ในพื้นหลัง (ขณะอยู่ในถาดระบบก็ตรวจเป็นระยะ) และติดตั้งเมื่อปิดแอปหรือเมื่อเปิดครั้งถัดไป โดยไม่ขัดจังหวะเกมที่กำลังบันทึกเวลาเล่น; หลังติดตั้งจะแสดงรายการเปลี่ยนแปลง; แพ็กเกจอัปเดตดาวน์โหลดจาก CNB ก่อน หากล้มเหลวจะใช้ GitHub (Velopack)
