上流の Starward をベースに、よく使う操作をデスクトップショートカットと 1 本の URL にまとめ、ガチャ、戦績、ゲームのインストール、背景などを強化しています。主な機能：

#### ガチャ

- **ガチャ記録** — ガチャ統計はドラッグで並べ替え可能、統計は上部に固定。リスト表示とコンパクトなアイコングリッド表示を切り替え可能。連続 UP / 連続外れ、すり抜けない確率などが一目で分かる
- **絞り込みと共有** — タイトルバーのドロップダウンで表示するガチャを選択、全選択 / 反転 / リセットに対応。フロストスタイルの共有画像をワンクリック生成し、天井カウントと確定天井の進捗を含める
- **ガチャ同期** — 原神（中国サーバー）とゼンレスゾーンゼロは米游社から記録を同期でき、ゼンレスゾーンゼロは HoYoLAB にも対応。未収録の新アイテムを引いたときはアイコンと名前を自動補完。アイテム名はアプリの言語に追従
- **星々の幻境** — 祈願記録ページはガチャ記録ページと同じ機能（絞り込み、コンパクト表示、ドラッグ並べ替え、共有画像）。上流で欠けているアイテムアイコンを補完
- **UIGF** — UIGF 形式のガチャ記録のインポート / エクスポートに対応

#### 戦績とツールボックス

- **毎日のチェックイン** — 米游社 / HoYoLAB のチェックイン。ゲームごとに独立したスイッチ、自動チェックインと事後チェックインに対応。トレイ常駐中は毎日のリセット後に自動でもう一度チェックイン
- **ログイン改善** — 中国サーバーは携帯電話番号で認証コードを受信してログイン、国際サーバーはウェブログイン。ログイン期限切れ時はできるだけ自動更新し、何度も再ログインしなくて済む
- **戦績の自動更新** — アカウントとデータ項目（月報の当月と先月を含む）ごとに更新頻度を設定し、アプリ起動時に自動で更新
- **月報とリアルタイム便箋** — ツールボックスの月報（開拓カレンダー / インターノット月次レポート / 旅人手帳）のレイアウトを統一。インターノット月次レポートはサーバーのタイムゾーンで日次データを集計し、既定で当月を表示。原神のリアルタイム便箋はより多くの項目を表示。リスク制御に当たったときは認証入口を提供
- **戦績の表示** — 戦績と月報は共有画像を生成可能。幻想シアターでは体験キャラと助演キャラを表示し、Anomaly Arbitration ではクイッククリアと難易度名を表示
- **クラウドゲーム** — クラウド原神とクラウドゼンレスゾーンゼロの残りプレイ時間を確認でき、毎日の無料時間を自動で受け取れる

#### 起動

- **複数の起動設定** — 同一ゲームに複数の起動パラメータとカスタム起動プログラムを保存でき、数に上限なし。設定ごとに DX12 パラメータと CMD 経由で起動するかを個別に設定でき、名前を付けて保存しデスクトップショートカットを作成できる
- **サードパーティツール** — カスタム起動プログラムには URL プロトコルのリンクも指定可能。よく使うコマンドライン引数に BetterGI、ゼンレスゾーンゼロ一条龍（OneDragon）、March7th Assistant のグループを内蔵
- **URL プロトコル** — `moonward://` でゲーム、設定、アカウントを指定して直接起動 / 停止 / 再起動、チェックインだけを実行することも可能。スクリプトやウェブページに埋め込める（詳細は [docs/UrlProtocol](UrlProtocol.md)）
- **クイック起動** — ホームのハンバーガーメニューにゲーム設定、クイック起動、ゲームのショートカットを統合。ショートカットは UAC プロンプトなしで起動でき、対応するタスクスケジューラのタスクは設定からゲームごとに管理できる
- **プレイ時間** — ゲーム実行中は「ゲーム開始」ボタンにタイマーを表示。プレイ時間の統計はゲームの切り替え、年月の指定、共有画像の生成に対応。PC がスリープしていた時間はプレイ時間に含めない

#### インストールと更新

- **ハードリンクのサーバー** — ゲームを更新・修復するとき、ハードリンクでファイルを共有しているほかのサーバーも一緒に処理（常に本体から先に更新）。アンインストールダイアログは同じゲームのインストール済みサーバーをすべて表示し、まとめてアンインストールできる
- **インストールオプション** — ゼンレスゾーンゼロは完全リソースか基本リソースかを選択可能。インストール先の横にディスクの種類（SSD / HDD / リムーバブル / ネットワーク）を表示。Chunk ダウンロードはチャンク単位で並列実行
- **修復とバージョン情報** — ゲームの修復は独立したダイアログになり、Miliastra Sandbox だけを修復することも可能。検証スレッド数はディスクの種類に合わせて調整。ゲーム設定の「バージョン情報」ページにバージョン、差分パッチ、メイン実行ファイルの MD5 を表示。自動検索でアプリ内でインストールした（ハードリンクを含む）ゲームを見つけ直せる

#### 外観と背景

- **好感度壁紙** — ゼンレスゾーンゼロでは百科の「好感度ダイナミック壁紙」と「マインドスケープ静止壁紙」をダウンロードしてカスタム背景に設定可能。ランダムモードでは起動時、ゲーム切り替え時、トレイから開いたときに壁紙を変更。ギャラリーを開くとローカルキャッシュを使い、バックグラウンドで更新を静かに確認
- **カスタム背景** — 独立したカスタム背景ダイアログ、画像 / 動画に対応（ホームにドラッグして直接差し替え可能）。背景リスト更新後もポスターの設定を保持
- **動画背景** — ハードウェアでデコードできない動画背景は自動で H.264 に変換。HEVC / VP9 拡張機能がない場合はインストールを案内するか静止画を表示。画面オフ中はデコードを解放し、CPU を無駄に使わない
- **ホームのツールバー** — タイムライン（ガチャ / イベントのカウントダウン）、中国サーバーの予告番組交換コード、インタラクティブマップ（原神 / 崩壊：スターレイル）

#### その他

- **トレイ常駐** — サインイン時にトレイへ起動する設定が可能。常駐中もグローバルホットキーとゲームパッド操作が使え、トレイメニューからそれらのオン / オフや更新の確認ができる
- **LAN 同期** — ローカルネットワーク上の別のデバイスからガチャ記録、ツールボックスのデータ、プレイ時間を取り込む。この PC にない記録だけを追加し、アカウントのログイン情報は同期しない
- **データ管理** — データベース、キャッシュ、ログ、背景を選んだフォルダーにまとめて保存。設定からデータベースのバックアップやキャッシュの削除が可能。初回起動時に上流 Starward からデータをインポートできる（読み取り専用で、元のデータは変更しない）
- **フィードバック** — バージョン情報ページから環境情報をワンクリックで事前入力して GitHub のフィードバックページを開き、同時にログフォルダーを開く
- **サイレント更新** — 新しいバージョンをバックグラウンドでダウンロード（トレイ常駐中も定期的に確認）し、終了時または次回起動時にインストール。プレイ時間を記録中のゲームがあるときは中断しない。インストール後に更新内容を表示。更新パッケージはまず CNB からダウンロードし、失敗したら GitHub を使う（Velopack）
