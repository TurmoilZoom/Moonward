在上游 Starward 的基礎上，把常用操作收進桌面捷徑與一條 URL，並在抽卡、戰績、遊戲安裝、背景等方面做了增強。主要功能：

#### 抽卡

- **抽卡紀錄** — 卡池統計可拖曳排序、統計吸頂；可在清單與緊湊圖示格線兩種檢視間切換；連 UP / 連歪、不歪機率等一目了然
- **篩選與分享** — 標題列下拉篩選顯示哪些卡池，可全選 / 反選 / 重設；一鍵產生磨砂風格分享圖，含墊數與保底進度
- **抽卡同步** — 原神（國服）與絕區零可從米遊社同步紀錄，絕區零也支援 HoYoLAB；抽到未收錄的新物品時自動補全圖示與名稱；物品名跟隨應用語言
- **千星奇域** — 頌願紀錄頁與抽卡紀錄頁功能一致（篩選、緊湊檢視、拖曳排序、分享圖）；補全上游缺少的物品圖示
- **UIGF** — 支援 UIGF 抽卡紀錄匯入 / 匯出

#### 戰績與工具箱

- **每日簽到** — 米遊社 / HoYoLAB 簽到，每個遊戲獨立開關，支援自動簽到與補簽；常駐系統匣時每日重新整理後自動再簽一次
- **登入改進** — 國服用手機號碼收驗證碼登入，國際服走網頁登入；登入過期時盡量自動續上，不必反覆重新登入
- **自動更新戰績** — 按帳號與資料板塊（含月報的當月與上月）分別設定更新頻率，軟體啟動時自動重新整理
- **月報與便箋** — 工具箱月報（開拓月曆 / 繩網月報 / 旅行者札記）版面統一；繩網月報按伺服器時區統計每日資料、預設顯示當月；原神即時便箋顯示更多內容；遇風控時提供驗證入口
- **戰績展示** — 戰績與月報可產生分享圖；幻想真境劇詩標出試用與助演角色，異相仲裁顯示快速通關與王棋難度
- **雲端遊戲** — 查看雲原神與雲絕區零的可用時長，可每天自動領取免費時長

#### 啟動

- **多啟動設定** — 同一遊戲可儲存多套啟動參數與自訂啟動程式，數量不限；每套可單獨設定 DX12 參數與是否經 CMD 啟動，可命名儲存並產生桌面捷徑
- **第三方工具** — 自訂啟動程式也可填 URL 通訊協定連結；常用命令列參數內建 BetterGI、絕區零一條龍、三月七小助手分組
- **URL 通訊協定** — `moonward://` 指定遊戲、設定與帳號直接啟動 / 停止 / 重新啟動，也可單獨觸發簽到；能嵌入指令碼或網頁（詳見 [docs/UrlProtocol](UrlProtocol.zh-CN.md)）
- **快速啟動** — 首頁漢堡選單整合遊戲設定、快速啟動與遊戲捷徑；捷徑可免 UAC 啟動，設定中可按遊戲管理對應的排程工作
- **遊戲時長** — 遊戲執行時在開始遊戲按鈕上顯示計時；時長統計可切換遊戲、指定年月並產生分享圖；電腦睡眠的時間不計入時長

#### 遊戲安裝與更新

- **硬連結區服** — 更新、修復遊戲時一併處理透過硬連結共用檔案的其他區服（總是先更新本體）；解除安裝對話方塊列出同一遊戲的全部區服，可一併解除安裝
- **安裝選項** — 絕區零可選完整資源或基礎資源；安裝路徑旁標出磁碟類型（SSD / HDD / 卸除式 / 網路）；Chunk 下載按區塊並行
- **修復與版本資訊** — 修復遊戲改為獨立對話方塊，可單獨修復千星沙箱，校驗執行緒數隨磁碟類型調整；遊戲設定的「版本資訊」頁列出版本、增量修補與主程式 MD5；自動尋找可找回在軟體內安裝（含硬連結）的遊戲

#### 外觀與背景

- **好感壁紙** — 絕區零可將百科「好感動態壁紙」與「滿影畫靜態壁紙」下載並設為自訂背景；隨機模式在啟動、切換遊戲或從系統匣開啟時換一張；開啟圖庫即用本機快取，背景靜默校驗更新
- **自訂背景** — 獨立的自訂背景對話方塊，支援圖片 / 影片（可拖入首頁直接取代）；背景清單更新後保留海報偏好
- **影片背景** — 無法硬體解碼的影片背景自動轉碼為 H.264；缺少 HEVC / VP9 擴充功能時引導安裝或改顯示靜態圖；螢幕關閉後釋放解碼，不再空佔 CPU
- **首頁工具列** — 時間節點（卡池 / 活動倒數）、國服前瞻直播兌換碼、互動地圖（原神 / 星穹鐵道）

#### 其他

- **系統匣常駐** — 可開機自啟到系統匣；常駐時全域快速鍵與手把控制仍然可用，系統匣選單可快速開關這些功能、檢查更新
- **區域網路同步** — 從區域網路內另一台裝置拉取抽卡紀錄、工具箱資料與遊戲時長，只新增本機沒有的紀錄，不同步帳號登入資訊
- **資料管理** — 資料庫、快取、記錄與背景統一存放在所選目錄下，設定中可備份資料庫、清除快取；首次啟動可從上游 Starward 匯入資料（唯讀，不改動原資料）
- **問題回饋** — 關於頁一鍵預填環境資訊並開啟 GitHub 回饋頁，同時開啟記錄資料夾
- **靜默更新** — 背景下載新版本（常駐系統匣時也會定時檢查），結束時或下次啟動時安裝，有遊戲正在記錄時長時不會打斷；裝好後顯示更新內容。更新套件優先從 CNB 下載，失敗時改用 GitHub（Velopack）

安裝套件見 [GitHub Releases](https://github.com/TurmoilZoom/Moonward/releases)，中國大陸也可從 [CNB](https://cnb.cool/TurmoilZoom/Moonward/-/releases) 下載。
