На основе upstream Starward часто используемые действия собраны в ярлык на рабочем столе и один URL; усилены гача, боевые записи, установка игр, фоны и другое. Основные возможности:

#### Гача

- **Записи гачи** — статистику баннеров можно переставлять перетаскиванием, она закрепляется вверху; переключение между списком и компактной сеткой значков; серии UP / промахов и шанс выиграть 50/50 видны сразу
- **Фильтры и шаринг** — выпадающий список в заголовке выбирает, какие баннеры показывать: выбрать все / инвертировать / сбросить; одним кликом — картинка для шаринга в стиле матового стекла с откручиванием и прогрессом гаранта
- **Синхронизация гачи** — Genshin Impact (китайский сервер) и Zenless Zone Zero синхронизируют записи из miHoYo BBS, Zenless Zone Zero также поддерживает HoYoLAB; для новых предметов, которых ещё нет в каталоге, иконки и названия подставляются автоматически; названия предметов следуют языку приложения
- **Астральный Предел** — страница записей молитв работает так же, как страница записей гачи (фильтры, компактный вид, перестановка перетаскиванием, картинка для шаринга); недостающие в upstream иконки предметов дополнены
- **UIGF** — импорт / экспорт записей гачи в формате UIGF

#### Боевые записи и набор инструментов

- **Ежедневный чекин** — чекин miHoYo BBS / HoYoLAB, отдельный переключатель для каждой игры, авточекин и доначисление; при работе в трее чекин повторяется после каждого ежедневного сброса
- **Улучшенный вход** — китайский сервер: вход по коду с телефона; международный — через веб; при истечении сессии вход по возможности продлевается автоматически, без повторного логина
- **Автообновление записей** — частота обновления задаётся для каждого аккаунта и раздела данных (включая текущий и прошлый месяц в месячных отчётах); записи обновляются автоматически при запуске приложения
- **Месячные отчёты и записки** — единый макет месячных отчётов в наборе инструментов (Календарь Освоения / Ежемесячный отчет Интернот / Заметки Путешественника); отчёт Интернот считает дневные данные по часовому поясу сервера и по умолчанию показывает текущий месяц; записки в реальном времени для Genshin Impact показывают больше данных; при срабатывании антифрода есть вход для проверки
- **Показ записей** — боевые записи и месячные отчёты можно сохранить картинкой для шаринга; в Театре воображения отмечены пробные и приглашённые персонажи, в Anomaly Arbitration показаны быстрые прохождения и названия сложностей
- **Облачные игры** — просмотр оставшегося времени Cloud Genshin и Cloud Zenless Zone Zero и автоматическое получение ежедневного бесплатного времени

#### Запуск

- **Несколько профилей запуска** — неограниченное число наборов аргументов запуска и пользовательских лаунчеров для одной игры; у каждого профиля свои настройки аргумента DX12 и «запуска через CMD»; профиль можно назвать и создать ярлык на рабочем столе
- **Сторонние инструменты** — пользовательским лаунчером может быть и ссылка URL-протокола; в частых аргументах командной строки есть группы для BetterGI, ZZZ OneDragon и March7th Assistant
- **URL-протокол** — `moonward://` с указанием игры, профиля и аккаунта запускает / останавливает / перезапускает игру или только выполняет чекин; можно встраивать в скрипты или веб-страницы (подробнее: [docs/UrlProtocol](UrlProtocol.md))
- **Быстрый запуск** — меню-гамбургер на главной объединяет настройки игры, быстрый запуск и ярлыки игры; ярлыки могут запускаться без запроса UAC, а связанные задачи планировщика управляются по играм в настройках
- **Игровое время** — пока игра запущена, на кнопке «Начать игру» идёт таймер; статистика игрового времени умеет переключать игры, выбирать год и месяц и создавать картинку для шаринга; время сна ПК не учитывается

#### Установка и обновления

- **Серверы с жёсткими ссылками** — при обновлении или восстановлении игры заодно обрабатываются другие серверы, делящие с ней файлы через жёсткие ссылки (основная установка всегда обновляется первой); диалог удаления показывает все установленные серверы той же игры и может удалить их вместе
- **Параметры установки** — для Zenless Zone Zero можно выбрать полные или базовые ресурсы; рядом с путём установки указан тип диска (SSD / HDD / съёмный / сетевой); загрузка chunk идёт параллельно по блокам
- **Восстановление и сведения о версии** — восстановление игры вынесено в отдельный диалог и может восстановить только Miliastra Sandbox; число потоков проверки подбирается под тип диска; страница «Сведения о версии» в настройках игры показывает версию, инкрементальные патчи и MD5 основного исполняемого файла; автопоиск находит игры, установленные через приложение (включая жёсткие ссылки)

#### Внешний вид и фон

- **Обои доверия** — в Zenless Zone Zero «динамические обои доверия» и «статичные обои Mindscape» из вики можно скачать и поставить как пользовательский фон; случайный режим меняет обои при запуске, смене игры или открытии из трея; галерея сразу использует локальный кэш, обновления тихо проверяются в фоне
- **Пользовательский фон** — отдельный диалог для изображения / видео (можно перетащить на главную для замены); после обновления списка фонов сохраняется выбор постера
- **Видеофоны** — видео, которые нельзя декодировать аппаратно, автоматически перекодируются в H.264; если нет расширения HEVC / VP9, приложение подскажет, как его установить, или покажет статичное изображение; при выключенном экране декодер освобождается и больше не нагружает CPU
- **Панель инструментов главной** — хронология (обратный отсчёт баннеров / событий), коды из спецтрансляций (китайский сервер) и интерактивные карты (Genshin Impact / Honkai: Star Rail)

#### Прочее

- **Работа в трее** — можно запускаться в трей при входе в систему; глобальные горячие клавиши и управление геймпадом продолжают работать, а меню трея позволяет переключать их и проверять обновления
- **Синхронизация по LAN** — записи гачи, данные набора инструментов и игровое время забираются с другого устройства в локальной сети; добавляются только записи, которых нет на этом ПК, данные входа в аккаунт не синхронизируются
- **Управление данными** — база данных, кэш, журналы и фоны хранятся в одной выбранной папке; в настройках можно сделать резервную копию базы и очистить кэш; при первом запуске можно импортировать данные из upstream Starward (только чтение, исходные данные не меняются)
- **Обратная связь** — страница «О программе» одним кликом заполняет сведения об окружении, открывает страницу issue на GitHub и папку журналов
- **Тихие обновления** — новые версии скачиваются в фоне (в трее тоже проверяются периодически) и ставятся при выходе или при следующем запуске, не прерывая игру, время которой сейчас записывается; после установки показывается список изменений; пакеты обновлений сначала скачиваются с CNB, а при ошибке — с GitHub (Velopack)
