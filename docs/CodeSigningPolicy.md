# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## Project

**Moonward** is an open-source third-party launcher for miHoYo / HoYoverse PC games (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Honkai Impact 3rd). It is maintained as a public fork of [Scighost/Starward](https://github.com/Scighost/Starward) under the [MIT License](../LICENSE).

- Source repository: [TurmoilZoom/Moonward](https://github.com/TurmoilZoom/Moonward)
- Official downloads: [GitHub Releases](https://github.com/TurmoilZoom/Moonward/releases)
- Project homepage: [https://turmoilzoom.github.io/Moonward/](https://turmoilzoom.github.io/Moonward/)

We only request code signing for **our own** release artifacts built from this repository. We do not sign binaries belonging to unrelated projects.

## What is signed

Windows release packages published on [GitHub Releases](https://github.com/TurmoilZoom/Moonward/releases), including (as produced by the release pipeline):

- Installer (`Setup.exe`) and portable packages
- Application executables and related binaries packaged for distribution (e.g. Velopack packages)

Unsigned upstream or third-party redistributable components may be included inside packages when required, but are not re-signed under this project’s SignPath subscription except as allowed by [SignPath Foundation conditions](https://signpath.org/terms.html).

## Build and signing process

1. Release artifacts are built from this public repository using continuous integration ([`.github/workflows/release.yml`](../.github/workflows/release.yml)).
2. Only CI-built artifacts from this repository are submitted to SignPath for signing.
3. The code signing private key is generated and stored by SignPath on an HSM. This project does **not** store or export the private key.
4. Each signing request is subject to manual approval by an Approver (see below).

Users should download Moonward only from the official [GitHub Releases](https://github.com/TurmoilZoom/Moonward/releases) page (or mirrors explicitly listed by the maintainer).

## Team roles

This is a single-maintainer project. Roles map to the same person until additional trusted maintainers are added.

| Role | Responsibility | Members |
|------|----------------|---------|
| **Authors** (committers) | Trusted to modify source code and build scripts in this repository | [@TurmoilZoom](https://github.com/TurmoilZoom) |
| **Reviewers** | Review changes proposed by non-committers (e.g. pull requests) before merge | [@TurmoilZoom](https://github.com/TurmoilZoom) |
| **Approvers** | Approve each SignPath signing request for a release | [@TurmoilZoom](https://github.com/TurmoilZoom) |

Policy:

- External pull requests are reviewed by the maintainer before merge.
- Each signing request requires explicit approval by an Approver.
- Repository and SignPath access use multi-factor authentication where available.

## Privacy policy

See [Privacy Policy](./Privacy.md).

In summary: usage data generated by Moonward is stored on the user’s device. Network requests (for example game / account services, optional metadata updates, or application updates) occur when the user installs, runs, or configures the software for those features. Third-party online services (e.g. miHoYo / HoYoverse, GitHub) are subject to their own privacy policies.
