在上游 Starward 的基础上，把常用操作收进桌面快捷方式与一条 URL，并在抽卡、战绩、游戏安装、背景等方面做了增强。主要功能：

#### 抽卡

- **抽卡记录** — 卡池统计可拖拽排序、统计吸顶；可在列表与紧凑图标网格两种视图间切换；连 UP / 连歪、不歪概率等一目了然
- **筛选与分享** — 标题栏下拉筛选显示哪些卡池，可全选 / 反选 / 重置；一键生成磨砂风格分享图，含垫数与保底进度
- **抽卡同步** — 原神（国服）与绝区零可从米游社同步记录，绝区零也支持 HoYoLAB；抽到未收录的新物品时自动补全图标与名称；物品名跟随应用语言
- **千星奇域** — 颂愿记录页与抽卡记录页功能一致（筛选、紧凑视图、拖拽排序、分享图）；补全上游缺失的物品图标
- **UIGF** — 支持 UIGF 抽卡记录导入 / 导出

#### 战绩与工具箱

- **每日签到** — 米游社 / HoYoLAB 签到，每个游戏独立开关，支持自动签到与补签；托盘常驻时每日刷新后自动再签一次
- **登录改进** — 国服用手机号收验证码登录，国际服走网页登录；登录过期时尽量自动续上，不必反复重新登录
- **自动更新战绩** — 按账号与数据板块（含月报的当月与上月）分别设定更新频率，软件启动时自动刷新
- **月报与便笺** — 工具箱月报（开拓月历 / 绳网月报 / 旅行札记）布局统一；绳网月报按服务器时区统计每日数据、默认显示当月；原神实时便笺展示更多内容；遇风控时提供验证入口
- **战绩展示** — 战绩与月报可生成分享图；幻想真境剧诗标出试用与助演角色，异相仲裁显示快速通关与王棋难度
- **云游戏** — 查看云原神与云绝区零的可用时长，可每天自动领取免费时长

#### 启动

- **多启动配置** — 同一游戏可保存多套启动参数与自定义启动程序，数量不限；每套可单独设置 DX12 参数与是否经 CMD 启动，可命名保存并生成桌面快捷方式
- **第三方工具** — 自定义启动程序也可填 URL 协议链接；常用命令行参数内置 BetterGI、绝区零一条龙、三月七小助手分组
- **URL 协议** — `moonward://` 指定游戏、配置与账号直接启动 / 停止 / 重启，也可单独触发签到；能嵌入脚本或网页（详见 [docs/UrlProtocol](docs/UrlProtocol.zh-CN.md)）
- **快速启动** — 首页汉堡菜单集成游戏设置、快速启动与游戏快捷方式；快捷方式可免 UAC 启动，设置中可按游戏管理对应的计划任务
- **游戏时长** — 游戏运行时在开始游戏按钮上显示计时；时长统计可切换游戏、指定年月并生成分享图；电脑睡眠的时间不计入时长

#### 游戏安装与更新

- **硬链接区服** — 更新、修复游戏时一并处理通过硬链接共用文件的其他区服（总是先更新本体）；卸载对话框列出同一游戏的全部区服，可一并卸载
- **安装选项** — 绝区零可选完整资源或基础资源；安装路径旁标出磁盘类型（SSD / HDD / 可移动 / 网络）；Chunk 下载按块并发
- **修复与版本信息** — 修复游戏改为独立对话框，可单独修复千星沙箱，校验线程数随磁盘类型调整；游戏设置的「版本信息」页列出版本、增量补丁与主程序 MD5；自动查找可找回在软件内安装（含硬链接）的游戏

#### 外观与背景

- **好感壁纸** — 绝区零可将百科「好感动态壁纸」与「满影画静态壁纸」下载并设为自定义背景；随机模式在启动、切换游戏或从托盘打开时换一张；打开画廊即用本地缓存，后台静默校验更新
- **自定义背景** — 独立的自定义背景对话框，支持图片 / 视频（可拖入首页直接替换）；背景列表更新后保留海报偏好
- **视频背景** — 无法硬件解码的视频背景自动转码为 H.264；缺少 HEVC / VP9 扩展时引导安装或改显示静态图；熄屏后释放解码，不再空占 CPU
- **首页工具栏** — 时间节点（卡池 / 活动倒计时）、国服前瞻直播兑换码、互动地图（原神 / 星穹铁道）

#### 其他

- **托盘常驻** — 可开机自启到托盘；常驻时全局快捷键与手柄控制仍然可用，托盘菜单可快速开关这些功能、检查更新
- **局域网同步** — 从局域网内另一台设备拉取抽卡记录、工具箱数据与游戏时长，只添加本机没有的记录，不同步账号登录信息
- **数据管理** — 数据库、缓存、日志与背景统一存放在所选目录下，设置中可备份数据库、清理缓存；首次启动可从上游 Starward 导入数据（只读，不改动原数据）
- **问题反馈** — 关于页一键预填环境信息并打开 GitHub 反馈页，同时打开日志文件夹
- **静默更新** — 后台下载新版本（托盘常驻时也会定时检查），退出时或下次启动时安装，有游戏正在记录时长时不会打断；装好后展示更新内容。更新包优先从 CNB 下载，失败时改用 GitHub（Velopack）
