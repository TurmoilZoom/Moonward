# 启动参数配置指南

Moonward 可以为每个游戏保存多套「怎么启动」的配置：命令行参数、自定义启动程序、绑定登录账号等。配置好之后，点「开始游戏」、生成桌面快捷方式，或通过 `moonward://` 链接启动，都能按你指定的方式运行。

在配置启动参数、生成快捷方式或编写 moonward:// 链接前，建议先阅读 URL 协议说明（注册方式、startgame / playtime 参数、game_biz 与 profile 等）：
[URL 协议（中文）](https://github.com/TurmoilZoom/Moonward/blob/rebase/develop/docs/UrlProtocol.zh-CN.md)
[URL Protocol (English)](https://github.com/TurmoilZoom/Moonward/blob/rebase/develop/docs/UrlProtocol.md)

本文从零说明：**入口在哪、能配什么、如何生效、和快捷方式/URL 有何关系**。

---

## 先分清两个概念

界面里有两处名字很像，但作用不同：

| 名称 | 在哪里 | 做什么 |
|------|--------|--------|
| **启动参数配置** | 开始游戏旁菜单 →「启动参数配置」 | **编辑**各套配置文件（参数、工具、账号等） |
| **启动参数**（选择启动方式） | 同一菜单里的下拉框 +「应用」 | 决定点「开始游戏」时 **实际用哪一套** |

可以记成：

- **配置** = 把菜谱写好（可以有很多份）
- **启动方式** = 今天真正按哪份菜谱做（当前生效的那一份）

默认生效方式是 **「无」**：不使用任何启动参数配置；若游戏设置里开了 DX12、无边框等全局开关，仍会照常附加。

---

## 一、打开配置界面

1. 在左侧选中要配置的游戏（原神 / 星铁 / 绝区零 / 崩坏 3 等，按区服区分）。
2. 点击主页「开始游戏」按钮旁的菜单（下拉箭头）。
3. 选择 **「启动参数配置」**。

会弹出标题为 **「启动参数配置」** 的对话框。

> 提示：每个游戏区服的配置相互独立，不会串。

---

## 二、认识配置文件

### 什么是配置文件？

一套配置文件通常包含：

- **配置名称**（显示用，可改）
- **命令行参数**（启动游戏时附加的参数）
- **自定义启动程序**（可选：用别的 exe/bat 来启动游戏）
- **登录账号**（可选，主要面向国服，配合米游社工具箱账号）

内部还会有一个固定编号，形如 `config1`、`config2`……  
显示名可以是「配置文件1」「无边框 1080P」等；编号在 URL 协议、快捷方式里会用到。

### 新建 / 切换 / 重命名 / 删除

| 操作 | 做法 |
|------|------|
| 切换配置 | 顶部「配置文件」下拉框 |
| 新建 | 下拉框旁的 **+** |
| 重命名 | 铅笔图标，编辑「配置名称」 |
| 删除 | 垃圾桶图标并确认 |

切换配置时若有未保存修改，会询问是否放弃。改完后请点 **「保存」**，否则不会写入。

数量没有硬性上限，可按用途拆多份，例如：

- 日常：默认窗口 / 分辨率  
- 多屏：指定显示器  
- 性能：强制某图形 API  
- 账号：绑定不同登录角色（国服）

---

## 三、配置命令行参数

### 1. 直接填写

在 **「命令行参数」** 输入框里填写，多个参数用空格分隔。例如：

```text
-popupwindow -screen-width 1920 -screen-height 1080
```

### 2. 用「常用参数」勾选（推荐新手）

输入框右侧有列表图标按钮（「勾选常用参数」）：

1. 打开面板  
2. 按分类勾选：显示模式、分辨率、图形 API、其他  
3. 需要数值的项（宽、高、显示器序号等）在面板里填  
4. 确认后会写回命令行输入框  

同组互斥项（例如窗口化 / 全屏）只能选一个。  
不认识的自定义参数仍可手写，会与勾选项合并。

### 3. 参数是否一定生效？

**不一定。** 米哈游 PC 客户端基于 Unity，参数是否被读取取决于游戏与引擎版本，部分可能被忽略。

界面中有指向 Unity 官方文档的链接：**「查看有关命令行参数的更多信息」**。

### 4. 与全局开关的关系

有些参数不必写在配置里，软件会在启动时自动附加：

| 开关位置（概念上） | 启动时可能附加 |
|--------------------|----------------|
| 游戏页 **使用 DX12 启动** 等 | `-use-d3d12`（开启时配置界面也可能显示只读徽章） |
| 游戏设置中的 **无边框窗口** 等 | `-popupwindow` |

配置里再写一遍可能重复；DX12 在部分场景下会由全局管理，勾选面板中对应项可能灰显。

> 选择启动方式为 **「无」** 时：不读配置里的命令行 / 自定义启动程序，但 **全局 DX12、无边框等仍会生效**。

---

## 四、自定义启动程序与 CMD

### 自定义启动程序

用于：用其它程序拉起游戏（启动器会把启动参数接在后面）。

1. 打开「启动参数配置」  
2. 在「自定义启动程序」旁点 **选择**，选 exe / bat 等  
3. 保存  

路径显示在下方，可点路径打开所在文件夹，或清除设置。

问号说明大意：选择其它程序启动游戏后，会把启动参数附加在其后。

### 使用 CMD 启动游戏

同对话框内可打开 **「使用 CMD 启动游戏」**。

用途之一是减少游戏内关于「检测到非法工具」一类提示（与社区讨论相关，视环境而定）。  
开启后会经 `cmd` 再启动游戏；是否与你的环境匹配请自行验证。

---

## 五、登录账号（国服）

对话框底部可选择 **「登录账号」**：

- 列表来自 **米游社工具箱** 中已添加的游戏角色  
- **「不指定」**：不按配置绑定账号  
- 选中某个 UID：启动前尽量换取登录票据，使游戏以该账号登录（**仅国服**；需对应 Cookie 含有效 `stoken`）

优先级简述：

1. URL / 快捷方式等调用时 **显式指定的 UID**（最高）  
2. 配置文件里保存的登录账号  
3. 其它全局自动登录逻辑（若开启）

国际服一般不依赖此路径；账号相关能力以实际界面与区服为准。

---

## 六、让配置「真正生效」

只保存配置文件 **还不够**。若希望点主页「开始游戏」就用某套配置：

1. 打开「开始游戏」旁菜单  
2. 在 **「启动参数」** 下拉中选择：  
   - **无** — 不用启动参数配置  
   - **配置文件 N / 你的自定义名** — 用该套  
3. 点 **「应用」**（出现勾表示已应用）

之后：

- 点 **开始游戏** → 使用当前生效方式  
- 不带 `profile` 的 `moonward://startgame/...`（「跟随软件设置」）→ 同样使用当前生效方式  

默认生效方式为 **「无」**。

---

## 七、桌面快捷方式（一键按某配置启动）

同一菜单中展开 **「游戏快捷方式」**：

1. 选择要绑定的启动方式：  
   - **跟随软件设置** — 始终跟当前生效方式  
   - **无** 或某个配置文件 — 固定用该方式  
2. （可选）勾选 **「关闭 UAC 提示」**（见下）  
3. 点 **「创建」**  

会在桌面生成快捷方式（本质多为 `moonward://` URL）。

### 注册 URL 协议

若尚未注册 `moonward://`，创建时可能提示是否注册。需同意后系统才能识别链接。  
也可在应用设置中管理 URL 协议开关。

### 关闭 UAC 提示（可选）

勾选后会创建「以最高权限运行」的计划任务，之后经该快捷方式启动时可减少 UAC 弹窗。  
**创建时可能需要管理员授权一次**。

不再需要时：

- 快捷方式帮助里可 **清理免 UAC 计划任务**，或  
- 在设置页相关说明中清理  

清理后，依赖这些任务的快捷方式会失效，需重新创建。

---

## 八、URL 指令（进阶，可选读）

配置对话框下方有 **「URL 指令预览」**，可复制当前配置对应的启动链接，例如：

```text
moonward://startgame/{game_biz}?profile=config1
```

| 参数 | 含义 |
|------|------|
| `game_biz` | 区服，如 `hk4e_cn`（原神国服）、`hkrpg_global`（星铁国际服） |
| `profile` | `none` = 无；`config1` / `config2`… = 对应配置；省略 = 跟随软件当前生效方式 |
| `uid` | 可选，指定角色 UID（国服自动登录，优先于配置内账号） |
| `install_path` | 可选，游戏安装目录 |

完整说明见仓库文档：[URL 协议（中文）](https://github.com/TurmoilZoom/Starward/blob/rebase/develop/docs/UrlProtocol.zh-CN.md)（路径以你实际仓库为准）。

浏览器、脚本、其它软件都可调用；前提是已注册协议。

---

## 九、推荐上手流程（最短路径）

1. 打开某游戏 → 菜单 → **启动参数配置**  
2. 用 **常用参数** 勾选需要的显示/分辨率项（或手写参数）  
3. 需要的话选 **登录账号**（国服）  
4. 点 **保存**  
5. 回到菜单 → **启动参数** 选中刚配的配置 → **应用**  
6. 点 **开始游戏** 验证  
7. （可选）**游戏快捷方式** → 选同一配置 → **创建**

## 十、常见问题

**Q：配了参数，点开始游戏没变化？**  
A：检查是否在菜单里 **应用** 了对应启动方式；默认是「无」。改完配置后记得 **保存**。

**Q：参数写了但不生效？**  
A：可能被游戏忽略；或与全局 DX12/无边框重复/冲突。可先用「无」+ 全局开关对比排查。

**Q：「无」和空配置有什么区别？**  
A：「无」完全不走启动参数配置（无命令行配置、无自定义启动程序、不读配置内登录账号）。空参数的配置文件仍算「用了配置」，只是参数字符串为空。

**Q：多个配置怎么给不同快捷方式？**  
A：创建快捷方式时分别选不同 `profile`；或复制 URL 预览里不同 `profile=` 的链接。

**Q：自定义启动程序找不到了？**  
A：路径失效时可能启动失败。请重新选择路径并保存。使用「配置文件1」的旧路径逻辑时，软件可能清理失效的默认路径记录。

**Q：删除配置后快捷方式还能用吗？**  
A：固定指向该 `configN` 的快捷方式/URL 可能失效或回退行为异常，请重新创建或改指向仍存在的配置。

## 附录：常用参数示意（勾选面板）

仅作入门参考，以软件内文案与实际效果为准：

| 类别 | 示例 | 作用简述 |
|------|------|----------|
| 显示 | 窗口化 / 全屏 / 无边框 / `-popupwindow` | 窗口模式 |
| 分辨率 | `-screen-width` / `-screen-height` / `-monitor` | 分辨率与显示器 |
| 图形 | `-force-d3d11` / `-use-d3d12` / `-force-vulkan` 等 | 图形 API 相关 |
| 其他 | `-nolog`、`-single-instance` 等 | 日志、单实例等 |

---

## 小结

1. 在 **启动参数配置** 里维护多套配置并保存。  
2. 在菜单 **启动参数** 中选择方式并 **应用**，主页启动才会用它。  
3. 全局 DX12、无边框等与配置独立，即使用「无」也可能附加参数。  
4. 桌面快捷方式与 URL 可固定某配置或跟随软件设置，依赖 `moonward://` 协议注册。  

按「九、推荐上手流程」走一遍，一般就能完成从配置到生效的全流程。
